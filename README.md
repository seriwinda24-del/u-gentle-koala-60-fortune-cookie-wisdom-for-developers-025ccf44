# The 2 A.M. Code Review

One original fortune-cookie line for a software developer.

## The fortune

> The code you wrote at 2 a.m. will review you at 9 a.m.

54 characters. The line is true about a developer's day — late-night code
meets the morning code review — and turns it around: the code you wrote
reviews *you*, not the other way round. The quiet twist is the role
reversal, and the second read lands on the 2 a.m. / 9 a.m. mirror: the
hours are seven apart, but the judgement is the same code. The line was
picked from ideas brainstormed with two AI helpers (Gemini and xKiro) and
chosen for the freshest angle: the code itself as the reviewer.

## Run

```sh
python3 main.py
```

Writes the fortune to `/output/entry.txt`.
